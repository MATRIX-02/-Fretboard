Cross-device access

Set up your account backend

Fretwork works fully offline without this. Connecting Firebase adds sign-in and syncs your progress to every device you use — phone, laptop, anywhere.

What you get

Sign in

Google one-tap, or email and password. Guest mode still works with no account at all.

Sync

Practise on your phone in the morning, open your laptop at night, and the streak is already there.

Safe merging

Devices are merged, never overwritten. Two devices used on the same day keep both sessions.

Setup — about 15 minutes, free

  1. Go to console.firebase.google.com and create a project (turn Analytics off — you don't need it).
  2. Build → Authentication → Get started. Enable Email/Password, Google, and Anonymous.
  3. Build → Firestore Database → Create database, production mode, pick the region closest to you.
  4. In Firestore → Rules, paste the rules below and publish.
  5. Project settings ⚙ → Your apps → Web (</>). Register the app, then copy the firebaseConfig values it shows you.
  6. Paste those values into assets/js/firebase-config.js and reload this page.

Firestore security rules

These make each user's data readable and writable only by them. Without them your database is open to anyone.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /fretwork_users/{userId} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}
Hosting on GitHub Pages. Once your site is live at yourname.github.io/fretwork, add that domain in Firebase under Authentication → Settings → Authorized domains, or Google sign-in will be rejected. Full deployment steps are in SETUP.md.

Use it on your other devices

  1. Open the same site URL on your phone or other computer.
  2. Sign in with the same account.
  3. Your weeks, streak, sessions, songs and goals appear within a second or two.
How conflicts are handled. Devices are merged, not overwritten — practice days, sessions, songs and completed weeks are combined from both sides. Only preferences (reminder time, session length) take the most recently changed device's value.
