🎵 Reference tuner

Play a reference pitch and match your string to it by ear. Tuning by ear is a skill worth building — it trains pitch discrimination that a needle tuner never will.

Tuning tip: tune up to the note, never down to it. If you're above the pitch, drop below first and come back up — that takes the slack out of the machine head and the string holds.
